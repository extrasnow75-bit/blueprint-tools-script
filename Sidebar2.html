Deploy Activity Directions (No AI)

What Does This Tool Do?

It copies directions from your finished model module into the other modules you check off. You choose which activities to deploy and which modules receive them, and the tool pastes the model’s wording as-is — no AI and no rewording. Use this when your activities are consistent enough that the same directions work across modules.

Model module

Select the module you set up with “Create Model Module.” Its directions will be copied to the checked modules below.

Activities to deploy

Choose which of the model module’s activities to copy. Only the checked activities are written into the target modules.
