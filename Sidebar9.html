      Rows that need a decision

      These rows either have no obvious activity in the Development tab, or were matched on a guess. Pick where each one belongs, or leave it skipped. Rows matched confidently are not listed, and unticking a row above removes it from here.

      Activities that already have directions

      Skipped by default so nothing is overwritten. Tick a box to paste the matching Design Map content into that Dev tab activity slot, above the directions already there.

        4. Highlight the pasted notes?

        Cyan blue is the IDC convention for “note to self, delete before this goes to the SME”. It makes the copied Design Map notes easy to find and strip out once the directions are written. The module objectives are never highlighted — those are real course content that stays.
