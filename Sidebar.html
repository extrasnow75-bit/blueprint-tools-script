What Does This Tool Do?

It reads the Course Pattern Table in your Design tab and builds out the Development tab from it. Using proper Blueprint formatting, this tool inserts the activity titles in each module, tags each one with its Canvas tool (Page, Assignment, Discussion, etc.), and adds a time estimate. Run this first — the other tools build on the structure it creates.

Unrecognized Canvas Tools

These entries in your Course Pattern Table don’t match a Canvas tool, so those activities keep the “Select Tool” placeholder instead of a real tool name. Pick the right tool for each.
