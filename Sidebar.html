What does this tool do?

It reads the Course Pattern Table in your Design tab and adds the following to the Development tab in proper Blueprint formatting:

  • activity titles
  • Canvas tools (Page, Assignment, Discussion, etc.)
  • time estimates
  • “Due by…” markers
  • extra modules past Module 7 (if requested)

The Blueprint template ships with seven modules. Enter a larger number below and this tool builds the rest.

When should I run this?

Run this tool first, after you’ve filled out the Course Pattern Table in the Design tab.

Questions about Blueprint setup

“activity titles” is unticked in Customize below, so this applies only to activity slots that have to be created.

Not in use — “time estimates” is unticked in Customize below.

Not in use — “Due by…” markers is unticked in Customize below.

Unrecognized Canvas Tools

These entries in your Course Pattern Table don’t match a Canvas tool, so those activities keep the “Select Tool” placeholder instead of a real tool name. Pick the right tool for each.
